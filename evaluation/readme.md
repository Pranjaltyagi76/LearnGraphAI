# Frozen evaluation definition v1

**State:** fixtures/protocol defined, no evaluator or model-quality run yet. Infrastructure smoke results are separate. [scenarios.v1.json](scenarios.v1.json) has 24 compact synthetic learner cases: 4 training, 8 development, 12 public final-audit cases. [manifest.v1.json](manifest.v1.json) freezes memberships, hashes, catalog/configuration, and random baseline seed 761120.

The annotations were authored from stated scenario assumptions before a production diagnosis/recommendation function exists; no production output generated labels. They express acceptable instructional gaps and expected policy behavior, **not latent causal truth**. Test cases are public and visible during review, not blind/secret or evidence of real-world generalization. Do not tune on final-audit outputs or claim an untouched holdout after doing so; author a newly versioned independent final audit and disclose its exposure if tuning is necessary.

Learner IDs and scenario groups are disjoint across splits; public demo profiles are excluded. Duplicate full observation patterns across splits are rejected. The same twelve question IDs and broad scenario families occur across splits, so there is no item-held-out or unseen-family claim. This small deterministic audit cannot justify bootstrap confidence intervals or a headline learning benefit. The six additional future-catalog blueprints cover equal-rank branches, multiple paths, depth boundaries, tag/graph perturbations, and ingestion limits; they are definitions, not runnable full-catalog evidence.

## Phase 2 runner contract

1. Initialize each learner from the prior with an empty history. These events are evaluation observations, not public demo seeds. For each eligible first response with known zero hints, predict from the **preceding** prefix, record outcome only afterward, then update state. Keep hinted/retried/lesson exclusions in counts. Never pass annotations, archetype names, expected states, or gap labels as inference inputs.
2. Fit global rate from eligible training events only with prior (2,2); per-concept baseline uses the frozen learner-prefix smoothing. No parameter fitting or threshold tuning on test. Primary prediction metrics: log loss (clip only the metric at epsilon 1e-15) and Brier. ROC AUC uses pairwise ranking with half credit for equal predictions. The public pr_auc field means stepwise average precision (recall-increment-weighted precision), not trapezoidal interpolation; group equal scores at one threshold. Both require both response classes; otherwise null with a reason. Report positive/negative and excluded-event counts.
3. Diagnose retrospectively at the final failed focus response using the full case prefix; no failure returns no_failed_trigger. Compare lowest estimate and prerequisite-aware heuristic on the same depth≤3 universe/eligibility. Report Precision/Recall@1/@3, MRR, coverage and no-gap false diagnosis rate using the denominators in [benchmark.md](../context/benchmark.md). annotation.evaluation_group explicitly separates labeled_gap, no_gap_control, missing_evidence, and no_trigger_control. False diagnosis rate uses only no_gap_control cases; report missing/no-trigger behavior separately, with all four counts. Blueprint-only cases have no metric denominator.
4. Compare fixed-seed random eligible, lowest-estimate-first, and prerequisite-aware plans under identical catalog/readiness constraints. Report catalog validity, prerequisite validity, distinct reassessment and exhaustion honesty, with applicable case/item counts; undefined ratios are null with reasons. No result is expected to beat a comparator by a prescribed margin.
5. Save exact commit/environment, input/catalog/config/split hashes, per-case outputs, denominators/exclusion counts, failures, and metric definitions. Publish measured aggregate results only after execution. Repeating an exposed public audit is regression evidence, not a new independent trial.

Randomness is only for the declared eligible-selection comparator; deterministic baseline/ranking uses no random seed. Use exact rational policy comparisons and stable ties. All content is synthetic original project material, with license still unselected; no EdNet/private records or training service is needed. New larger datasets/generator variants require their own manifest, provenance, split policy, and claims.
